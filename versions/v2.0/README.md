## Historical root definition

Definition 2.0 used the following English root definition:

> **Human function is the body's capacity to be appropriately engaged for real-world tasks.**

This wording established the task-centered operational entry point of Version 2.0. It is preserved here for historical accuracy. MUFO Definition 2.1 later clarified that the complete philosophical scope is not limited to real-world tasks and adopted the current authoritative expression:

> **Human function is the body's capacity to be appropriately engaged to meet internal and external demands.**

The compact Chinese philosophical root definition remained:

> **人体功能，就是身体被正常调用的能力。**

## Principal contribution

MUFO Definition 2.0 moved MUFO from the factor-and-score-centered emphasis of V1.0 toward a broader ontology architecture for task-centered human-function reasoning.

It established:

- Human Function as a shared domain object represented in computational systems;
- Functional Engagement as a task-conditioned organization process;
- a governed semantic coordinate system rather than a terminology list or ordinary knowledge graph;
- separation between observation and inference;
- explicit safety and professional-scope constraints;
- four person-level task-centered state classes;
- a continuous execution, feedback, reassessment, and write-back loop;
- separation among MUFO, the Individual Human Function Model (IHFM), and the Human Function World Model (HFWM);
- bidirectional disease–function reasoning;
- semantic coordination of specialized AI models.

## Functional Engagement

Version 2.0 described Functional Engagement as the process through which the body organizes the resources required to undertake a specified real-world task. These resources could include structural support, functional capacities, sensory feedback, motor control, energy supply, protective responses, recovery regulation, cognitive participation, and behavioral participation.

It distinguished producing a task outcome from establishing appropriate Functional Engagement.

The task-centered operational conditions were:

1. task goal achievable;
2. organization relatively stable;
3. associated cost controllable.

Safety remained a separate constraint layer.

## Core semantic state–action spine

The high-level semantic spine was:

> **Task → Engagement → Manifestation → Cost → Boundary → State → Action → Feedback**

The fuller operational inference sequence was:

> **Safety Boundary → Task → Required Engagement → Actual Engagement → Manifestation → Cost → Boundary → Limiting-Factor Hypotheses → Evidence Convergence → Primary Problem → State → Action Direction → Execution → Feedback → Reassessment → Write-back**

This sequence was intended to prevent premature attribution and to preserve the distinction between observed facts and candidate explanations.

## Four task-centered states

Definition 2.0 used four foundational person-level task-centered state classes:

| State | Historical functional interpretation |
|---|---|
| **Normal** | The task is achievable; engagement is relatively stable; cost is controllable; usable reserve remains. |
| **Compensatory** | The task remains achievable, but engagement has changed and a higher cost is being paid. |
| **Critical** | The task may remain achievable, but reserve has substantially narrowed and small demand changes may cross the current boundary. |
| **Functional Incapacity** | Required engagement cannot be effectively established or maintained; the task is impossible or severely limited. |

These state classes were not medical diagnoses or permanent labels.

## Three-layer architecture

Definition 2.0 separated:

### 1. MUFO

MUFO defines and governs the human-function domain through objects, relations, constraints, evidence semantics, state rules, safety boundaries, action semantics, feedback semantics, provenance, and versioning.

### 2. Individual Human Function Model — IHFM

The IHFM records one person's longitudinal state and history within the semantic coordinates provided by MUFO.

### 3. Human Function World Model — HFWM

The HFWM adds time, action, transition, and prediction, modeling how a person's represented state may change under context, exposure, history, and action.

The development progression was expressed as:

> **MUFO → Individual Human Function Model → Human Function World Model**

## Disease–function reasoning

Definition 2.0 explicitly treated disease and human function as distinct but bidirectionally connected objects:

- disease, injury, surgery, medication, abnormal tests, and pathological mechanisms may affect structures, capacities, recovery, safety boundaries, task tolerance, and engagement strategies;
- persistent compensation, repeated exposure beyond boundaries, narrowing reserve, declining recovery, repeated unexplained manifestations, and longitudinal decline in life-task ability may become candidate risk signals for clinical review.

This was framed as upward signal reasoning, not autonomous diagnosis.

## Relationship to Version 2.1

Definition 2.0 remains valid as a task-centered operational formalization. Version 2.1 does not erase that contribution.

Definition 2.1 supersedes the Version 2.0 English root definition and upper-level scope by:

- introducing internal and external Demand as the full organizing range;
- treating real-world tasks as a principal specialization of External Demand rather than the total boundary;
- separating Task from Task Demand;
- generalizing Functional Engagement from task-conditioned to demand-conditioned organization;
- distinguishing domain objects, processes, inferences, and versioned information representations more strictly;
- limiting the four-state framework to its current person-level task-centered scope;
- extending the intended Human Function World Model trajectory toward multiscale physiological, behavioral, environmental, and whole-person modeling.
