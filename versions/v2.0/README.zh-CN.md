## 历史英文根定义

Definition 2.0 使用的英文根定义为：

> **Human function is the body's capacity to be appropriately engaged for real-world tasks.**

这一表述建立了 V2.0 的任务中心运行入口，为保证版本真实性予以保留。MUFO Definition 2.1 后续明确：人体功能的完整哲学范围并不局限于现实任务，并采用当前权威英文表达：

> **Human function is the body's capacity to be appropriately engaged to meet internal and external demands.**

中文哲学根定义始终保持为：

> **人体功能，就是身体被正常调用的能力。**

## 主要贡献

MUFO Definition 2.0 将 V1.0 以因素、评分和任务—能力匹配为重点的运行框架，推进为一套更完整的任务中心人体功能本体架构。

V2.0 主要建立了：

- 将人体功能作为计算系统中的共同领域对象；
- 将 Functional Engagement 定义为任务条件下的身体组织过程；
- 建立受治理的统一语义坐标，而不是普通术语表或普通知识图谱；
- 严格区分观察与推断；
- 引入显式安全边界与专业权限约束；
- 建立四类人级任务中心人体功能状态；
- 建立执行、反馈、复评与持续回写闭环；
- 区分 MUFO、个人人体功能模型（IHFM）与人体功能世界模型（HFWM）；
- 建立疾病—功能双向推理；
- 为不同专业 AI 模型提供语义协调层。

## Functional Engagement

V2.0 将 Functional Engagement 描述为：身体为了完成一个明确现实任务，对所需资源进行组织的过程。

这些资源可以包括：

- 结构支持；
- 功能能力；
- 感觉反馈；
- 动作控制；
- 能量供应；
- 保护反应；
- 恢复调节；
- 认知参与；
- 行为参与。

V2.0 明确区分：

> **完成了任务结果**

与

> **建立了适当的功能调用。**

任务中心运行条件为：

1. 任务目标可达；
2. 组织相对稳定；
3. 相关代价可控。

安全边界仍然作为独立约束层存在。

## 核心语义状态—行动主轴

V2.0 的高层语义主轴为：

> **任务 → 调用 → 表现 → 代价 → 边界 → 状态 → 行动 → 反馈**

更完整的运行判断顺序为：

> **安全边界 → 任务 → 所需调用 → 实际调用 → 表现 → 代价 → 边界 → 限制因素假设 → 证据收束 → 主矛盾 → 状态 → 行动方向 → 执行 → 反馈 → 复评 → 回写**

这条顺序用于防止过早归因，并要求把观察事实与候选解释分开。

## 四类任务中心状态

Definition 2.0 使用四类基础的人级任务中心状态：

| 状态 | 历史运行解释 |
|---|---|
| **正常状态** | 任务可达，调用相对稳定，代价可控，并保留可用余量。 |
| **代偿状态** | 任务仍可完成，但调用方式已经改变，并以更高代价维持。 |
| **临界状态** | 任务可能仍可完成，但余量明显缩小，较小的需求变化就可能越过当前边界。 |
| **失能状态** | 完成任务所需调用无法被有效建立或维持，任务明确不能完成或严重受限。 |

这四类状态不是医学诊断，也不是永久身份标签。

## 三层架构

Definition 2.0 明确区分三层：

### 1. MUFO

MUFO 通过对象、关系、约束、证据语义、状态规则、安全边界、行动语义、反馈语义、来源和版本，定义并治理人体功能领域。

### 2. 个人人体功能模型——IHFM

IHFM 在 MUFO 提供的语义坐标中，记录一个具体人的长期状态与历史。

### 3. 人体功能世界模型——HFWM

HFWM 在此基础上加入时间、行动、迁移和预测，建模一个人的表示状态如何随情境、暴露、历史和行动而变化。

发展关系被表达为：

> **MUFO → 个人人体功能模型 → 人体功能世界模型**

## 疾病—功能双向推理

V2.0 明确把疾病与人体功能视为不同但双向连接的对象：

- 疾病、损伤、手术、用药、异常检查和病理机制，可以影响结构、能力、恢复、安全边界、任务耐受和调用策略；
- 持续代偿、反复超过边界、余量持续收窄、恢复下降、无法解释的表现反复出现，以及生活任务能力长期下降，可以成为提交临床复核的风险候选信号。

后者属于向上风险线索推理，不等于自动疾病诊断。

## 与 Definition 2.1 的关系

Definition 2.0 作为任务中心运行形式化仍然有效，Definition 2.1 并没有否定或删除这一贡献。

Definition 2.1 对 V2.0 的英文根定义和上层范围进行了替代与扩展性澄清，主要包括：

- 将内部需求与外部需求确立为完整组织范围；
- 将现实任务视为外部需求的重要运行特化，而不是人体功能的全部边界；
- 区分 Task 与 Task Demand；
- 将 Functional Engagement 从任务条件组织泛化为需求条件组织；
- 更严格地区分领域对象、过程、推断和版本化信息表示；
- 明确四状态仅适用于当前人级任务中心框架；
- 将人体功能世界模型的发展范围扩展到多尺度生理、行为、环境和整个人的状态建模。
